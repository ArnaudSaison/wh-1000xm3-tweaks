Upload

    Keep the headset on and nearby, and do not close this page. A false low-battery warning afterwards cleared last time after a power cycle or charge. Recovery from a failed upload may require opening the headset.

    Firmware: buttons

    Changes how long buttons are held before they act, and can add a double press for pairing. This replaces the headset's code, using your region's Sony file.

    Hold times of 4 s, and of 1 s with 3 s, have run on a real headset, and so has a first version of the double press. The current double press, with its wait before the pairing sound, has not. An upload takes about 16 minutes. If the headset accepts a file and it doesn't boot, recovery needs SPI access, which isn't set up yet. The headset could be left unusable.

      What the power button does with these values

      From off, the firmware can't time anything until it has booted, about 2 s on the one headset measured (inferred). The press and release paths are read from the code and observed on the headset. The moves out of pairing are read or inferred, and "released early" is inferred. Holding on through power-off was seen to bring the headset back on, and the code then starts pairing, which hasn't been checked on the headset. The double click is only drawn, and only built, with the option ticked. A first version works on the headset. The current one, which waits three seconds so the pairing announcement isn't cut off, is emulated only: see docs/double-press.md. Your phone's reaction is untested.
