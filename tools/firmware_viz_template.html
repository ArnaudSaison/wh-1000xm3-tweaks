      One signature block: 32 words

      A bug in the signature's hash means only the first 17 words of each block count. The other 15 can change while Sony's signature stays valid. Those 15 are the bright columns in the map.

      Why there is no padding to use

      The code segment is packed: its longest run of empty words is one word. The zero runs in the constants are mostly real table data, and code may not be able to run from there. So the patch reuses functions that nothing refers to.

      What the lights are

      Each lit word is an instruction the emulator ran, from real firmware code. Firmware calls, sound, LEDs and radio are models, and RAM doesn't come from a real boot. The double-press patch hasn't run on a headset yet.

      What this page holds

      A type for each word, addresses, names we gave to functions, and the order of execution. It holds no firmware bytes or disassembly.

      How sure each finding is

      Confirmed means checked on the headset or against Sony's signatures. Read means seen directly in the code. Inferred is our best interpretation. Most of the file still has no name.
